## 0. 文档说明

### 0.1 范围

本规格覆盖 Demo 阶段（1学派=儒家 + 1主武器=射艺 + 教学波 + 1Boss=儒宗师阶段1-2）所有玩家可见界面的流程、布局、交互逻辑。不展开 v1.9 完整版界面。

### 0.2 灰模 UX 原则

| 原则 | 说明 |
|------|------|
| 功能优先 | 文字标签 + 几何体边框 + 矩形条即可，不需要精美图标 |
| 键盘全可达 | 所有界面必须能纯键盘操作，不依赖鼠标点击（依赖 ADR-002 输入抽象层）|
| 百分比坐标 | 所有 HUD 元素用屏幕百分比定位，适配不同分辨率 |
| 过渡极简 | 灰模阶段所有状态转换用 200ms 淡入淡出，无动画特效 |

## 1. 状态机流程图（UX 视角）

### 1.1 状态-界面映射总表

### 1.3 转换触发条件与过渡效果

| 源状态 | 目标状态 | 触发条件 | 过渡效果 | 玩家操作 |
|--------|---------|---------|---------|---------|
| Boot | MainMenu | 配置加载完成 | 黑屏→淡入主菜单 200ms | 无（自动）|
| MainMenu | CharacterSelect | 选择"开始游戏" | 淡出→淡入 200ms | Enter / 鼠标左键 |
| CharacterSelect | WavePlaying | 确认学派+主武器选择 | 淡出→淡入战斗 200ms | Enter 确认 |
| WavePlaying | WaveIntermission | 所有敌人死亡 | 淡出战斗→淡入面板 200ms | 无（自动）|
| WaveIntermission | WavePlaying | 选择"继续下一波" | 淡出面→淡入战斗 200ms | Enter |
| WaveIntermission | BossPlaying | 波5后选择"继续" | 淡出→淡入 Boss 战 200ms | Enter |
| BossPlaying | Shop | Boss1 被击败 | 淡出→淡入商店 200ms | 无（自动）— **Demo 不触发** |
| Shop | BossPlaying | 选择"离开商店" | 淡出→淡入 Boss 战 200ms | Enter — **Demo 不触发** |
| BossPlaying | WaveIntermission | Boss2 被击败 | 淡出→淡入面板 200ms | 无（自动）|
| BossPlaying | VictoryScreen | Boss3 被击败 | 淡出→淡入 200ms | 无（自动）|
| WavePlaying/BossPlaying | DeathScreen | 玩家 HP 归零 | 暗色遮罩淡入 300ms + 死亡面板 200ms | 无（自动）|
| DeathScreen | MainMenu | 选择"退出到主菜单" | 淡出→淡入 200ms | Enter |
| DeathScreen | CharacterSelect | 选择"重新开始" | 淡出→淡入 200ms | Enter |
| VictoryScreen | MainMenu | 选择"退出到主菜单" | 淡出→淡入 200ms | Enter |
| VictoryScreen | CharacterSelect | 选择"重新开始" | 淡出→淡入 200ms | Enter |

> **Demo 通关条件**: 击败儒宗师阶段2。Boss3 在 Demo 范围内不出现，VictoryScreen 在儒宗师阶段2被击败后触发。

### 1.4 Demo 范围简化说明

ADR-004 定义了完整的 3 Boss 流程。Demo 范围只有 1 个 Boss（儒宗师阶段1-2），因此实际流程为：

```
CharacterSelect → WavePlaying(波1教学) → WaveIntermission → WavePlaying(波2...波5)
→ BossPlaying(儒宗师阶段1-2) → VictoryScreen
```

- **器物店不嵌入 Demo 游戏流程**：主理人决策——Demo 不在游戏流程中触发器物店。§5 器物商店章节保留为 **UI 原型规格**，供 S43(items.json) 和 S45(Shop UI) 产出数据定义+UI 原型使用，但玩家在 Demo 游戏流程中不会进入 Shop 状态。
- **不存在 Boss2/Boss3 流程**：相关状态转换在 Demo 中不触发。

**屏幕坐标区域**（百分比，左下角为原点 0,0）：

| 元素 | 左边界 | 右边界 | 下边界 | 上边界 |
|------|-------|-------|-------|-------|
| 标题"选择学派" | 35% | 65% | 80% | 90% |
| 学派槽位1（儒家）| 15% | 30% | 40% | 65% |
| 学派槽位2（法家）| 35% | 50% | 40% | 65% |
| 学派槽位3（道家）| 55% | 70% | 40% | 65% |
| 确认提示 | 35% | 65% | 15% | 25% |

**Demo 范围**：
- 槽位1「儒家」：可选。显示金色圆形几何体预览 + 文字"击杀治愈+5HP"。
- 槽位2「法家」：灰色半透明 + 文字"锁定"（Demo 不可选）。
- 槽位3「道家」：灰色半透明 + 文字"锁定"（Demo 不可选）。

**交互逻辑**：
- ←/→ 键在 3 个槽位间切换焦点。焦点框为白色高亮边框。

- Enter 确认选择 → 进入主武器选择界面。

### 2.3 确认→进入教学波的过渡

1. 玩家在主武器选择界面按 Enter 确认。
2. 画面淡出 200ms（全屏黑色遮罩 α 0→1.0）。
3. 加载战斗场景。
4. 画面淡入 200ms（遮罩 α 1.0→0）。
5. 教学波开始，HUD 淡入显示。

### 3.2 HP 条

| 属性 | 规格 |
|------|------|
| 位置 | 左下角，屏幕坐标 x:2%~12%, y:5%~12% |
| 样式 | 矩形条，红色填充（灰模：浅灰填充），深灰底框 |
| 尺寸 | 宽 10% 屏幕宽 × 高 3.5% 屏幕高 |
| 数值显示 | 条右侧显示 "当前HP/最大HP"（如 "85/100"）|
| 受伤反馈 | HP 条闪烁白色→红色 50ms（与半灰命中闪烁同步）|
| 治愈反馈 | HP 条平滑增长（200ms 缓动）|
| HP 归零 | HP 条变空 + 全屏暗色遮罩淡入 → DeathScreen |
| Demo 参数 | 最大 HP = 100，儒家被动击杀+5HP |

### 3.3 体力条（P0 — 道家闪避核心反馈）

> **引用**: GDD v0.2 §B 体力系统。可访问性分级 Standard §2.2 体力条可视化增强。

| 属性 | 规格 |
|------|------|
| 位置 | HP 条正下方，屏幕坐标 x:2%~12%, y:13.5%~18% |
| 样式 | 矩形条，青色填充（灰模：中灰填充），深灰底框 |
| 尺寸 | 宽 10% 屏幕宽 × 高 3% 屏幕高（略窄于 HP 条）|
| 数值显示 | 条右侧显示当前体力值（如 "60"）|
| 消耗反馈 | 闪避/冲刺时条即时缩短（无缓动，即时反映消耗）|
| 恢复反馈 | 条平滑增长（线性，恢复速度 5/秒 或道家 7.5/秒）|
| 体力不足 | 体力 < 闪避消耗阈值（普通20/道家10）时，条变红闪烁（α 0.5↔1.0，频率 2Hz）|
| 闪避冷却指示 | 冷却中在体力条下方显示细条进度（0→100%），道家不显示 |
| Demo 参数 | 体力池 100，普通消耗 20/次，恢复 5/秒 |

**闪避冷却倒计时**（Standard 级，引用可访问性分级 §2.2）：
- 位置：体力条下方 2px 处，宽度同体力条，高度 1% 屏幕高。
- 冷却中：填充从 0%→100% 线性增长，填满后消失。
- 道家学派：不显示（无冷却）。
- 御艺 Lv2+：冷却 3s，进度条 3s 填满。

### 9.2A 色盲友好模式 — UI 交互规格（Demo 实现）

> **主理人决策（Phase 4）**：色盲模式从 Standard 级（P1）升级为 Demo 实现。以下为完整 UI 交互规格。

#### 9.2A.1 进入方式

| 项目 | 规格 |
|------|------|
| 入口 | 暂停面板 → 设置 → 画面 → 色盲模式 |
| 操作 | ←→ 键循环切换：无 → 红绿色盲 → 蓝黄色盲 → 全色弱 → 无 |
| 即时生效 | 切换后立即生效，无需重启或确认 |
| 持久化 | 设置保存到 SaveSystem，下次启动自动加载 |

#### 9.2A.2 四种配色方案

| 模式 | 适用人群 | 弹幕配色变化 | HUD 配色变化 | 说明 |
|------|---------|------------|------------|------|
| **无**（默认）| 正常色觉 | 儒金(#FFD700) / 法黑(#1a1a1a) / 道青(#00CED1) | HP红 / 体力青 / Boss HP金 | 原始配色 |
| **红绿色盲**（Protanopia）| 红绿色觉缺失 | 儒→高对比蓝(#0066FF) / 法→深紫(#4B0082) / 道→亮黄(#FFD700) | HP→蓝 / 体力→黄 / Boss HP→蓝 | 儒金和道青改为蓝/黄高对比对 |
| **蓝黄色盲**（Tritanopia）| 蓝黄色觉缺失 | 儒→品红(#FF00FF) / 法→深绿(#006400) / 道→亮橙(#FF8C00) | HP→品红 / 体力→橙 / Boss HP→品红 | 道青改为橙色，与儒品红形成对比 |
| **全色弱**（Achromatomaly）| 全色觉减弱 | 所有弹幕→高对比度配色（纯黑/纯白/中灰交替）+ 加粗轮廓线 | HP→纯白 / 体力→中灰 / Boss HP→纯白加粗边框 | 最大化亮度对比，辅以轮廓线 |

#### 9.2A.3 形状辅助层（色盲模式不变）

> **关键原则**：色盲模式只改变颜色层，**不改变形状层**。灰阶可辨原则（Basic §1.1）确保弹幕形状本身可辨，色盲模式是颜色层的增强。

| 弹幕类型 | 形状（所有色盲模式下不变）| 轮廓线增强（全色弱模式）|
|---------|------------------------|----------------------|
| 儒家扩散 | 圆形 | 2px 白色轮廓 |
| 法家直线 | 直线锐角三角形 | 2px 白色轮廓 |
| 道家弧线 | 弧线/波纹圈 | 2px 白色轮廓 |
| 射艺箭矢 | 直线箭头 | 2px 白色轮廓 |

#### 9.2A.4 设置界面显示

色盲模式在设置界面（附录 A §A.2）的"画面"区域显示：

```
│  色盲模式:     [无] → [红绿色盲] → [蓝黄色盲]  │
│               → [全色弱] → [无]               │
│  当前: 无                                       │
```

- 当前选中的模式名称高亮显示（白色背景）。
- ←→ 切换时，当前模式名称即时更新。
- 切换后游戏画面即时变色，玩家可以在设置界面背后看到效果（设置面板半透明）。

#### 9.2A.5 与灰阶模式的关系

| 特性 | 灰阶可辨模式（Basic）| 色盲友好模式（Standard）|
|------|-------------------|----------------------|
| 切换键 | G 键（全局快捷）| 设置界面 ←→（无快捷键）|
| 效果 | 去掉所有颜色，只留灰度 | 替换为色盲友好配色 |
| 互斥 | 灰阶开启时色盲配色不可见（灰度覆盖）| 色盲模式开启时灰阶仍可叠加（灰阶优先）|
| 组合 | 灰阶 + 色盲 = 灰阶效果（色盲配色被灰度覆盖）| — |

> 两者可同时开启但灰阶优先。建议玩家二选一：色觉差异玩家用色盲模式，需要纯形状测试时用灰阶。

### C.2 为什么 Demo 不显示副技能图标内容

Demo 范围只有射艺（主武器），无副技能。副技能图标框预留位置但显示"无"。波1教学波后玩家可选副技能（v1.9 完整版功能），Demo 不展开副技能升级路径。

### C.3 为什么所有过渡用淡入淡出 200ms

半灰标准（GDD v0.2 §D）要求"功能优先，美观其次"。200ms 淡入淡出是最短可感知过渡——足以让玩家意识到场景切换，但不会造成等待感。正式版可替换为水墨晕染过渡。

### C.4 为什么 Boss 阶段切换阈值是 50%

Demo 范围儒宗师只有阶段1-2（GDD v0.2 §D.5 最小可验证单元定义）。阶段1 HP 100%→50%，阶段2 HP 50%→0%。阶段3（大同）不实现。50% 阈值确保玩家体验两个阶段的时间大致相等。
