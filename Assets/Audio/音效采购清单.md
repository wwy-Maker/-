## 0. 采购原则

### 0.1 许可证要求

**只使用 CC0（公有领域）或免费可商用许可的音效**。不使用需要署名的 CC-BY（Demo 阶段简化署名管理），不使用付费音效库。

| 许可证 | 可用 | 说明 |
|--------|------|------|
| CC0 (Public Domain) | ✅ 首选 | 无任何限制，不需署名，可商用 |
| Pixabay License | ✅ | 免费可商用，不需署名 |
| CC-BY | ⚠️ 备选 | 需署名，Demo 可用但需记录署名信息 |
| CC-BY-NC | ❌ | 不可商用 |
| 付费库 | ❌ | Demo 不付费 |

### 0.2 格式标准

| 参数 | 要求 | 理由 |
|------|------|------|
| 格式 | WAV ( uncompressed PCM) | 短音效无需压缩，加载快，无解码开销 |
| 采样率 | 44100 Hz | Unity 默认采样率，兼容性最好 |
| 位深 | 16-bit | 音效不需要 24-bit 动态范围 |
| 声道 | 单声道 (Mono) | 短音效不需要立体声定位，Mono 占用更小且 2D 弹幕游戏无需空间音效 |
| 时长 | 0.1-1.0s（因类型而异） | 短反馈音效，不干扰战斗节奏 |

### 0.3 文件命名规范

| 规范 | 说明 | 示例 |
|------|------|------|
| `sfx_` 前缀 | 所有音效文件统一前缀 | `sfx_shoot.wav` |
| 全小写下划线分隔 | 与灰模资产规格清单 §4.7 一致 | `sfx_boss_phase.wav` |
| 存放路径 | `Assets/_Project/Audio/` | 与主架构 §4 目录结构一致 |

## 2. 逐类采购方案

### 2.1 射击音效（sfx_shoot_archery.wav）

#### 音色描述

| 维度 | 描述 |
|------|------|
| 音色类型 | 短促"嗖"声——弓弦释放 + 箭矢破空 |
| 音高 | 中高频（弓弦"嗡"声在 800-2000Hz 范围） |
| 音量感 | 中等偏轻——射艺射速3发/秒，频繁播放不宜太响 |
| 包络 | 快速起音（Attack <5ms）→ 快速衰减（Decay 50-100ms）→ 无持续 |
| 参考类比 | 拨弦声 + 短促气流声，像用手指弹橡皮筋后接一声"嗖" |

#### 搜索关键词

| 平台 | 搜索关键词 |
|------|-----------|
| Freesound.org | `"bow shoot"`、`"arrow release"`、`"bowstring"`、`"arrow whoosh"` |
| Kenney.nl | Kenney "Audio" 系列包中的 "shoot" 或 "laser" 音效 |
| OpenGameArt | `"bow"`、`"arrow"`、`"projectile shoot"` |
| Pixabay | `"bow and arrow"`、`"arrow shoot sound effect"` |

#### 推荐来源

| # | 来源 | 具体位置 | 许可证 | 说明 |
|---|------|---------|--------|------|
| 1 | **Kenney.nl** | Kenney Audio Pack → "Audio UI" 或 "SciFi Sounds" 包中的短促射击音 | CC0 | Kenney 的射击音效偏"科幻激光"，但短促精炼，灰模阶段可用。首选 "Audio UI" 包中偏柔和的 shoot 音 |
| 2 | **Freesound.org** | 搜索 `"bow shoot"` 筛选 CC0 | CC0 | Freesound 上有大量真实弓箭录音。筛选时长 <0.3s 的 CC0 音效。推荐用户 "joedeshon" 的弓箭系列 |
| 3 | **OpenGameArt.org** | 搜索 `"bow"` 或 `"arrow"` 筛选 CC0 | CC0 | OpenGameArt 有游戏专用弓箭音效包。推荐 "Bow and Arrow Sound Pack" 类资源 |

#### 采购策略

1. **首选**：从 Kenney "Audio UI" 包下载——已打包好，无需逐个搜索，CC0 许可
2. **备选**：Freesound 搜索 `"bow shoot"` 筛选 CC0 + 时长 <0.3s
3. **最后手段**：如果以上都不满意，用任何短促"拨弦"音效降调处理——灰模阶段"哔"声都比没有好

#### 后处理要求

如果下载的音效需要微调：

| 处理 | 参数 | 说明 |
|------|------|------|
| 音量归一化 | Peak = -6dB | 统一音量基准，留出动态余量 |
| 裁剪 | 保留起音前 5ms + 尾部衰减完成处 | 去除静音部分，减少文件大小 |
| 淡出 | 尾部 20ms 线性淡出 | 避免截止噪声（click） |
| 降调（可选） | -2 ~ -4 semitones | 如果原音偏高/偏"激光感"，降调使其更"物理感" |

## 3. AudioMixer Group 方案

### 3.1 AudioMixer 结构

```
Master (主输出)
├── SFX (音效组)
│   ├── sfx_shoot_archery  ← 射击音
│   ├── sfx_hit_generic    ← 命中音
│   ├── sfx_dodge_dash     ← 闪避音
│   └── sfx_boss_phase     ← Boss阶段音
└── UI (UI音效组 — Demo阶段预留，暂不使用)
```

### 3.2 AudioMixer 参数

| Group | 音量 (dB) | 说明 |
|-------|----------|------|
| **Master** | 0 dB | 主输出，不衰减。可访问性 Basic §1.3 要求可调总音量 |
| **SFX** | -3 dB | 音效组输出限制 -3dB 防防爆音。可访问性 Basic §1.3 要求可调音效音量 |
| **UI** | -6 dB | 预留，Demo 阶段无 UI 音效 |

> **-3dB 防爆音**：SFX 组设为 -3dB 而非 0dB，因为多个音效同时播放时（如密集命中）会叠加导致削波。-3dB 留出约 1.4 倍的动态余量。Master 组的 Limiter 可作为最终保护。

### 3.3 AudioMixer 文件

| 文件 | 路径 | 说明 |
|------|------|------|
| `GameAudioMixer.mixer` | `Assets/_Project/Audio/GameAudioMixer.mixer` | Unity AudioMixer 资产 |

### 3.4 音量控制实现

可访问性 Basic §1.3 要求 Master 和 SFX 可独立调节：

```csharp
using UnityEngine;
using UnityEngine.Audio;

/// <summary>
/// 音量控制器。通过 AudioMixer 控制 Master 和 SFX 通道音量。
/// 设置界面提供两个滑块（UX 规格 由文策渊产出）。
/// </summary>
public class VolumeController : MonoBehaviour
{
    [SerializeField] private AudioMixer _audioMixer;
    
    private const string MasterVolumeKey = "MasterVolume";
    private const string SFXVolumeKey = "SFXVolume";
    
    /// <summary>
    /// 设置 Master 音量。
    /// </summary>
    /// <param name="volume">0.0 ~ 1.0 线性音量</param>
    public void SetMasterVolume(float volume)
    {
        // 线性 → dB 转换
        float dB = LinearToDB(volume);
        _audioMixer.SetFloat(MasterVolumeKey, dB);
    }
    
    /// <summary>
    /// 设置 SFX 音量。
    /// </summary>
    public void SetSFXVolume(float volume)
    {
        float dB = LinearToDB(volume);
        _audioMixer.SetFloat(SFXVolumeKey, dB);
    }
    
    /// <summary>
    /// 线性音量 (0~1) 转 dB。
    /// volume=0 → -80dB (静音)
    /// volume=1 → 0dB (原音量)
    /// </summary>
    private float LinearToDB(float volume)
    {
        if (volume <= 0.0001f)
            return -80f; // 静音
        return 20f * Mathf.Log10(volume);
    }
    
    /// <summary>
    /// 静音切换。
    /// </summary>
    public void ToggleMute(bool muted)
    {
        _audioMixer.SetFloat(MasterVolumeKey, muted ? -80f : 0f);
    }
}
```

### 3.5 AudioMixer Group 暴露参数

在 AudioMixer 窗口中需要 Expose 以下参数：

| Exposed Parameter 名 | 对应 Group | 用途 |
|---------------------|-----------|------|
| `MasterVolume` | Master | 总音量控制 |
| `SFXVolume` | SFX | 音效音量控制 |

## 4. AudioManager 设计

### 4.1 架构定位

### 4.2 AudioManager 伪代码

```csharp
using UnityEngine;

/// <summary>
/// 音效播放管理器。管理所有音效的播放、音量、节流。
/// 通过 ServiceLocator 注册为全局服务。
/// </summary>
public class AudioManager : MonoBehaviour
{
    // 音效引用（从配置或 Inspector 加载）
    private AudioClip _sfxShoot;
    private AudioClip _sfxHit;
    private AudioClip _sfxDodge;
    private AudioClip _sfxBossPhase;
    
    // 音量（从配置读取）
    private float _volumeShoot = 0.5f;
    private float _volumeHit = 0.7f;
    private float _volumeDodge = 0.6f;
    private float _volumeBossPhase = 0.8f;
    
    // 节流：同一音效 50ms 内最多播放 1 次
    private float _lastShootTime;
    private float _lastHitTime;
    private float _lastDodgeTime;
    private float _lastBossPhaseTime;
    private const float ThrottleInterval = 0.05f; // 50ms
    
    // AudioSource 池（避免频繁创建）
    private AudioSource[] _audioSources;
    private int _nextSourceIndex = 0;
    private const int AudioSourcePoolSize = 8;
    
    private void Awake()
    {
        // 初始化 AudioSource 池
        _audioSources = new AudioSource[AudioSourcePoolSize];
        for (int i = 0; i < AudioSourcePoolSize; i++)
        {
            _audioSources[i] = gameObject.AddComponent<AudioSource>();
            _audioSources[i].playOnAwake = false;
            _audioSources[i].outputAudioMixerGroup = // SFX group;
        }
    }
    
    /// <summary>
    /// 播放射击音效。50ms 节流。
    /// </summary>
    public void PlayShoot()
    {
        if (Time.time - _lastShootTime < ThrottleInterval) return;
        _lastShootTime = Time.time;
        PlayOneShot(_sfxShoot, _volumeShoot);
    }
    
    /// <summary>
    /// 播放命中音效。50ms 节流。
    /// </summary>
    public void PlayHit()
    {
        if (Time.time - _lastHitTime < ThrottleInterval) return;
        _lastHitTime = Time.time;
        PlayOneShot(_sfxHit, _volumeHit);
    }
    
    /// <summary>
    /// 播放闪避音效。50ms 节流。
    /// </summary>
    public void PlayDodge()
    {
        if (Time.time - _lastDodgeTime < ThrottleInterval) return;
        _lastDodgeTime = Time.time;
        PlayOneShot(_sfxDodge, _volumeDodge);
    }
    
    /// <summary>
    /// 播放Boss阶段转换音效。无节流（重要节点不节流）。
    /// </summary>
    public void PlayBossPhaseShift()
    {
        PlayOneShot(_sfxBossPhase, _volumeBossPhase);
    }
    
    private void PlayOneShot(AudioClip clip, float volume)
    {
        if (clip == null) return;
        
        // 轮询使用 AudioSource 池
        var source = _audioSources[_nextSourceIndex];
        _nextSourceIndex = (_nextSourceIndex + 1) % AudioSourcePoolSize;
        
        source.clip = clip;
        source.volume = volume;
        source.PlayOneShot(clip, volume);
    }
}
```

## 5. 音效触发规则

### 5.1 触发条件与音量

| 音效 | 触发条件 | 音量参考 | 节流 | 说明 |
|------|---------|---------|------|------|
| `sfx_shoot_archery` | 射艺每次发射箭矢时 | 0.5 | 50ms | 频繁播放（3发/秒），音量不宜过大 |
| `sfx_hit_generic` | 任意弹幕命中任意目标时 | 0.7 | 50ms | 命中反馈需清晰。密集命中时节流防炸耳 |
| `sfx_dodge_dash` | 玩家按下Shift闪避/御艺冲刺启动时 | 0.6 | 50ms | 中等音量 |
| `sfx_boss_phase_shift` | Boss进入新阶段(1→2, 2→3)时 | 0.8 | 无 | 重要节点不节流，需突出 |

### 5.2 节流规则

**同一音效在 50ms 内最多播放 1 次**（灰模资产规格清单 §3.4）。

实现方式：`AudioManager` 记录每个音效上次播放的时间戳，50ms 内的重复请求丢弃。

| 场景 | 无节流 | 有节流(50ms) |
|------|--------|-------------|
| 3发/秒射艺 | 正常播放，间隔333ms | 正常播放（333ms > 50ms） |
| 密集命中（10命中/100ms） | 10次播放→炸耳 | 2次播放（100ms/50ms=2） |
| Boss阶段转换 | 1次/阶段 | 1次/阶段（本就不密集） |
