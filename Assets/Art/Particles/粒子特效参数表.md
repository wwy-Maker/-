## 1. 命中闪烁（vfx_hit_flash）

### 1.1 实现方式

**不用 Particle System**——用 `SpriteRenderer.color` 协程覆盖实现。

原因：命中闪烁是50ms的瞬时颜色切换（白→红→原色），粒子系统过重且不适合精确控制单对象颜色。`SpriteRenderer.color` 直接覆盖是最轻量、最精确的方案。

### 1.2 视觉规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 阶段1 颜色 | 纯白 #FFFFFF (255,255,255) | 受击瞬间闪白 |
| 阶段1 持续时间 | 25ms | 极短，突出"击中感" |
| 阶段2 颜色 | 纯红 #FF3030 (255,48,48) | 红色冲击 |
| 阶段2 持续时间 | 25ms | 与阶段1等长 |
| 恢复 | 恢复受击前原色 | 立即恢复，无过渡 |
| 总时长 | 50ms | 两个25ms阶段 |

### 1.3 协程伪代码

```csharp
using UnityEngine;
using System.Collections;

/// <summary>
/// 命中闪烁控制器。
/// 挂载在任何需要受击反馈的实体（玩家、弟子、Boss）上。
/// 通过 SpriteRenderer.color 在 50ms 内完成 白→红→原色 三段切换。
/// 
/// 与灰阶后处理兼容：灰阶是渲染层后处理，命中闪烁是对象层着色，两者串行不冲突。
/// 灰阶下表现：白(亮度255)→红(亮度109)→原色，亮度差异足够可见。
/// 
/// 可访问性：命中闪烁是手感验证核心（半灰标准），简化视觉模式下不可关闭。
/// </summary>
[RequireComponent(typeof(SpriteRenderer))]
public class HitFlashController : MonoBehaviour
{
    private SpriteRenderer _renderer;
    private Coroutine _flashCoroutine;
    private Color _baseColor; // 当前基础色（非闪烁状态的颜色）
    
    // 闪烁颜色常量——从配置读取（ADR-001 数据驱动）
    // 此处硬编码为默认值，运行时由 ColorInjector 覆盖
    private static readonly Color FlashWhite = new Color(1f, 1f, 1f, 1f);         // #FFFFFF
    private static readonly Color FlashRed   = new Color(1f, 0.188f, 0.188f, 1f); // #FF3030
    
    // 闪烁时长常量
    private const float FlashPhaseDuration = 0.025f; // 25ms per phase
    private const float FlashTotalDuration = 0.05f;  // 50ms total
    
    private void Awake()
    {
        _renderer = GetComponent<SpriteRenderer>();
        _baseColor = _renderer.color;
    }
    
    /// <summary>
    /// 设置基础颜色（非闪烁状态的颜色）。
    /// 由 SpriteInitializer 或外部系统在颜色变化时调用。
    /// </summary>
    public void SetBaseColor(Color color)
    {
        // 如果正在闪烁，不覆盖（闪烁结束后会用 _baseColor 恢复）
        // 如果没在闪烁，直接应用
        if (_flashCoroutine == null)
        {
            _baseColor = color;
            _renderer.color = color;
        }
        else
        {
            _baseColor = color; // 闪烁恢复时使用新基础色
        }
    }
    
    /// <summary>
    /// 触发命中闪烁。
    /// 多次受击时重置协程（StopCoroutine + StartCoroutine），不叠加。
    /// </summary>
    public void TriggerHitFlash()
    {
        if (_flashCoroutine != null)
            StopCoroutine(_flashCoroutine);
        _flashCoroutine = StartCoroutine(HitFlashRoutine());
    }
    
    private IEnumerator HitFlashRoutine()
    {
        // 阶段1: 纯白，25ms
        _renderer.color = FlashWhite;
        yield return new WaitForSecondsRealtime(FlashPhaseDuration);
        
        // 阶段2: 纯红，25ms
        _renderer.color = FlashRed;
        yield return new WaitForSecondsRealtime(FlashPhaseDuration);
        
        // 恢复基础色
        _renderer.color = _baseColor;
        
        _flashCoroutine = null;
    }
    
    /// <summary>
    /// 如果对象在闪烁期间被回收到对象池，需停止协程。
    /// </summary>
    private void OnDisable()
    {
        if (_flashCoroutine != null)
        {
            StopCoroutine(_flashCoroutine);
            _flashCoroutine = null;
            _renderer.color = _baseColor; // 确保恢复基础色
        }
    }
}
```

## 2. 死亡碎裂（vfx_death_shatter）

### 2.1 实现方式

**Unity Particle System** —— 对象死亡时激活，发射 3-5 个碎片粒子，碎片继承死亡对象颜色，向外飞散后受重力下落，0.5s 内淡出。

### 2.2 Particle System 模块参数表

以下参数基于灰模资产规格清单 §1.8 和 §4.3 的要求，细化到每个 Particle System 模块的具体数值。

#### 主模块（Particle System Main Module）

| 参数 | 值 | 注释 |
|------|-----|------|
| Duration | 0.5s | 粒子系统总持续时间，等于碎片最长生命周期 |
| Looping | false | 不循环，死亡碎裂是一次性效果 |
| Start Delay | 0s | 无延迟，对象死亡立即触发 |
| Start Lifetime | Random Between Two Constants: 0.3 ~ 0.5s | 碎片存活时间随机化，避免整齐消失 |
| Start Speed | Random Between Two Constants: 2 ~ 5 | 向外飞散速度随机化，方向由 Shape 模块控制 |
| Start Size | Random Between Two Constants: 0.04 ~ 0.12 | 碎片尺寸 4-12px（0.04-0.12 单位），小碎片感 |
| Start Rotation | Random Between 0 ~ 360 | 碎片随机旋转，增加自然感 |
| Start Color | 继承父对象颜色 | 通过代码设置：`particleSystem.startColor = parentColor;` |
| Gravity Modifier | 1.5 | 重力影响系数，碎片有下落感但不会太快坠落。值域 1-2，1.5 为中值 |
| Simulation Space | World | 世界空间模拟——碎片飞散后不受父对象移动影响（父对象可能已销毁） |
| Simulation Speed | 1.0 | 正常速度 |
| Play On Awake | false | 不自动播放，由代码调用 Play() |
| Emitter Velocity Mode | Transform | 使用 Transform 速度作为发射器速度 |
| Max Particles | 5 | 最大粒子数 5，碎片不超过 5 片 |

#### Emission 模块

| 参数 | 值 | 注释 |
|------|-----|------|
| Rate over Time | 0 | 不持续发射，只 Burst |
| Rate over Distance | 0 | 不按距离发射 |
| Bursts | 1 次 Burst | 一次性爆发 |
| Burst Count | Random Between Two Constants: 3 ~ 5 | 3-5 片碎片 |
| Burst Time | 0s | 死亡瞬间立即 Burst |
| Burst Cycles | 1 | 只 Burst 一次 |

#### Shape 模块

| 参数 | 值 | 注释 |
|------|-----|------|
| Shape | Box | 盒形发射器，碎片从对象中心区域向各方向飞散 |
| Box X | 0.3 | 发射区域宽度 0.3 单位（约等于弟子 36px 的宽度） |
| Box Y | 0.3 | 发射区域高度 0.3 单位 |
| Box Z | 0 | 2D 游戏无 Z 轴 |
| Emit from | Edge | 从边缘发射，碎片向外飞散感更强 |
| Random Direction | true | 随机方向，碎片四散 |

> **备选 Shape**：Sphere（球形发射器）也可用，半径设为 0.15。Box 和 Sphere 效果接近，Box 略好——碎片从边缘飞出更有"碎裂"感。

### 2.3 生命周期管理

```csharp
/// <summary>
/// 死亡碎裂特效控制器。
/// 对象死亡时调用 Play()，0.5s 后自动将特效对象回收到对象池。
/// 
/// 使用方式：
/// 1. DeathShatter.prefab 放在对象池中预分配
/// 2. 对象死亡时：从对象池获取 DeathShatter 实例 → 设置颜色 → Play() → 0.5s 后回收
/// </summary>
[RequireComponent(typeof(ParticleSystem))]
public class DeathShatterController : MonoBehaviour
{
    private ParticleSystem _particleSystem;
    private ParticleSystemRenderer _renderer;
    
    private void Awake()
    {
        _particleSystem = GetComponent<ParticleSystem>();
        _renderer = GetComponent<ParticleSystemRenderer>();
    }
    
    /// <summary>
    /// 播放死亡碎裂特效。
    /// </summary>
    /// <param name="position">死亡位置（世界坐标）</param>
    /// <param name="deathColor">死亡对象的颜色（弟子=学派色，Boss=阶段色）</param>
    public void Play(Vector3 position, Color deathColor)
    {
        transform.position = position;
        
        // 设置碎片颜色
        var main = _particleSystem.main;
        main.startColor = deathColor;
        
        // 设置碎片 Sprite（从 SpriteGenerator 获取缓存的 8px 方块）
        _renderer.sprite = SpriteGenerator.Generate(SpriteShape.Square, 8);
        
        // 播放粒子
        _particleSystem.Play();
        
        // 0.5s 后回收到对象池
        StartCoroutine(ReturnToPoolAfterDelay(0.5f));
    }
    
    private IEnumerator ReturnToPoolAfterDelay(float delay)
    {
        yield return new WaitForSeconds(delay);
        _particleSystem.Stop();
        // ObjectPool.Return(this); // 回收到对象池
    }
}
```

### 2.5 简化视觉模式兼容

可访问性 Standard §2.3 规定简化视觉模式下关闭碎裂粒子，对象直接淡出：

```csharp
/// <summary>
/// 死亡视觉处理。根据简化视觉模式设置选择碎裂或淡出。
/// </summary>
public class DeathVisualHandler : MonoBehaviour
{
    [SerializeField] private bool _simplifiedVisualMode = false;
    
    /// <summary>
    /// 处理对象死亡视觉。
    /// </summary>
    public void HandleDeath(Vector3 position, Color deathColor, 
                            SpriteRenderer targetRenderer)
    {
        if (_simplifiedVisualMode)
        {
            // 简化模式：直接淡出 200ms
            StartCoroutine(SimpleFadeOut(targetRenderer, 0.2f));
        }
        else
        {
            // 正常模式：死亡碎裂
            var shatter = ObjectPool.Get<DeathShatterController>();
            shatter.Play(position, deathColor);
            // 隐藏原对象（立即消失，碎裂粒子代替视觉）
            targetRenderer.enabled = false;
        }
    }
    
    private IEnumerator SimpleFadeOut(SpriteRenderer renderer, float duration)
    {
        Color originalColor = renderer.color;
        float elapsed = 0f;
        while (elapsed < duration)
        {
            elapsed += Time.deltaTime;
            Color c = originalColor;
            c.a = Mathf.Lerp(1f, 0f, elapsed / duration);
            renderer.color = c;
            yield return null;
        }
        renderer.color = originalColor;
        renderer.enabled = false;
    }
}
```

## 3. Boss 阶段转换闪白（vfx_boss_phase_flash）

### 3.1 实现方式

**不用 Particle System**——用全屏 UI Image (ColorOverlay) 实现1帧白屏闪烁。

原因：全屏闪白是2D覆盖效果，Particle System 不适合全屏覆盖。UI Image + Canvas Group 控制最简单高效。

### 3.2 视觉规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 闪白颜色 | 纯白 #FFFFFF (255,255,255) | 全屏白色覆盖 |
| 闪白持续 | 1帧 (~16ms @60fps) | 极短，制造"闪光"感 |
| 透明度峰值 | α=0.8 | 不完全遮挡画面，让玩家感知到"闪了一下"但不会完全失明 |
| 淡出时间 | 100ms | 从 α=0.8 线性淡出到 α=0 |
| 总时长 | ~116ms | 1帧闪白 + 100ms淡出 |

### 3.3 实现方案

```
场景结构：
└── Game.unity
    └── Canvas (Screen Space - Overlay)
        └── PhaseFlashOverlay (UIImage, 全屏, 默认 disabled)
            └── Image (color=#FFFFFF, α=0)
```

```csharp
using UnityEngine;
using UnityEngine.UI;
using System.Collections;

/// <summary>
/// Boss 阶段转换闪白控制器。
/// 通过全屏 UI Image 实现白色闪烁效果。
/// 
/// 触发时机：BossSystem.EnterPhase() 中，Boss HP 降到阶段阈值时。
/// 同时播放 Boss 阶段转换音效（sfx_boss_phase_shift）。
/// </summary>
[RequireComponent(typeof(Image))]
public class PhaseFlashController : MonoBehaviour
{
    private Image _flashImage;
    
    [Header("闪白参数")]
    [SerializeField] private float _peakAlpha = 0.8f;      // 闪白峰值透明度
    [SerializeField] private float _flashDuration = 0.016f; // 1帧 @60fps
    [SerializeField] private float _fadeOutDuration = 0.1f; // 淡出 100ms
    
    private Coroutine _flashCoroutine;
    
    private void Awake()
    {
        _flashImage = GetComponent<Image>();
        _flashImage.color = new Color(1f, 1f, 1f, 0f); // 初始透明
        _flashImage.raycastTarget = false; // 不阻挡点击
    }
    
    /// <summary>
    /// 触发全屏闪白。
    /// </summary>
    public void Flash()
    {
        if (_flashCoroutine != null)
            StopCoroutine(_flashCoroutine);
        _flashCoroutine = StartCoroutine(FlashRoutine());
    }
    
    private IEnumerator FlashRoutine()
    {
        // 阶段1: 闪白（1帧）
        _flashImage.color = new Color(1f, 1f, 1f, _peakAlpha);
        yield return new WaitForSecondsRealtime(_flashDuration);
        
        // 阶段2: 淡出（100ms）
        float elapsed = 0f;
        while (elapsed < _fadeOutDuration)
        {
            elapsed += Time.unscaledDeltaTime;
            float alpha = Mathf.Lerp(_peakAlpha, 0f, elapsed / _fadeOutDuration);
            _flashImage.color = new Color(1f, 1f, 1f, alpha);
            yield return null;
        }
        
        // 确保完全透明
        _flashImage.color = new Color(1f, 1f, 1f, 0f);
        _flashCoroutine = null;
    }
}
```

```csharp
    _phaseFlashController.Flash();
    
    // 播放阶段转换音效
    AudioManager.Play("sfx_boss_phase_shift", volume: 0.8f);
    
    // Boss 脉冲动画（见 Sprite 生成方案 §5.2）
    StartCoroutine(PhaseTransitionPulse(_bossEntity.transform));
}
```

### 3.5 可访问性考量

| 模式 | 闪白表现 | 说明 |
|------|---------|------|
| 正常 | α=0.8 白屏闪1帧 + 100ms淡出 | 标准效果 |
| 灰阶模式 | 同上（白色在灰阶下仍为白色） | 灰阶不影响白色 |
| 简化视觉模式 | α=0.5 白屏闪1帧 + 100ms淡出 | 降低峰值透明度，减少视觉冲击 |

> **光敏性安全**：闪白持续1帧(~16ms)在光敏性安全范围内（<3Hz 闪烁频率）。Boss 阶段转换最多2次/局（阶段1→2、阶段2→3），不会连续闪烁。

## 4. 学识拾取消失（pickup_knowledge 拾取效果）

### 4.1 实现方式

**不用 Particle System**——用 `SpriteRenderer` 缩放协程实现拾取时的"缩放消失"效果。

### 4.2 视觉规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 拾取前 | scale=1.0, α=呼吸(0.6↔1.0, 0.8s周期) | 学识掉落物的正常状态 |
| 拾取触发 | scale 从 1.0 → 0.0, 100ms | 快速缩小消失 |
| 拾取后 | 对象回收到对象池 | |

### 4.3 协程伪代码

```csharp
/// <summary>
/// 学识拾取效果。拾取时缩放消失 + 可选播放拾取音效。
/// </summary>
public class KnowledgePickupEffect : MonoBehaviour
{
    private Transform _transform;
    private Coroutine _pickCoroutine;
    
    private const float PickDuration = 0.1f; // 100ms
    
    private void Awake()
    {
        _transform = transform;
    }
    
    /// <summary>
    /// 触发拾取消失效果。
    /// </summary>
    public void PlayPickupEffect()
    {
        if (_pickCoroutine != null)
            StopCoroutine(_pickCoroutine);
        _pickCoroutine = StartCoroutine(PickupRoutine());
    }
    
    private IEnumerator PickupRoutine()
    {
        Vector3 originalScale = _transform.localScale;
        float elapsed = 0f;
        
        while (elapsed < PickDuration)
        {
            elapsed += Time.deltaTime;
            float t = elapsed / PickDuration;
            // 缩放从 1.0 → 0.0
            _transform.localScale = originalScale * (1f - t);
            yield return null;
        }
        
        _transform.localScale = originalScale; // 恢复（对象池复用前）
        _pickCoroutine = null;
        
        // 回收到对象池
        // ObjectPool.Return(this);
    }
    
    /// <summary>
    /// 呼吸效果（学识掉落物的待拾取状态）。
    /// 在 Update 中持续运行。
    /// </summary>
    private void Update()
    {
        if (_pickCoroutine != null) return; // 拾取中不呼吸
        
        // α 0.6 ↔ 1.0, 周期 0.8s
        float alpha = Mathf.Lerp(0.6f, 1.0f, 
            (Mathf.Sin(Time.time * Mathf.PI / 0.4f) + 1f) / 2f);
        GetComponent<SpriteRenderer>().color = new Color(1f, 1f, 1f, alpha);
    }
}
```

## 5. 礼屏障呼吸效果（bullet_li_barrier 呼吸）

### 5.1 实现方式

**不用 Particle System**——用 `SpriteRenderer.color` alpha 协程实现屏障的呼吸效果。

### 5.2 视觉规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 呼吸范围 | α 0.6 ↔ 0.9 | 不透明度循环变化 |
| 呼吸周期 | 1s | 一次呼吸（0.6→0.9→0.6）耗时1秒 |
| 持续时间 | 5s | 屏障总持续时间 |
| 消失淡出 | 200ms | 屏障到期时 α 从当前值→0 |

### 5.3 协程伪代码

```csharp
/// <summary>
/// 礼屏障视觉效果控制器。
/// 呼吸效果 + 到期淡出。
/// </summary>
public class BarrierVisualController : MonoBehaviour
{
    private SpriteRenderer _renderer;
    
    private const float BreathMin = 0.6f;
    private const float BreathMax = 0.9f;
    private const float BreathPeriod = 1.0f; // 1秒一个周期
    private const float FadeOutDuration = 0.2f; // 200ms 淡出
    
    private float _remainingTime;
    private bool _isFadingOut = false;
    
    private void Awake()
    {
        _renderer = GetComponent<SpriteRenderer>();
    }
    
    /// <summary>
    /// 初始化屏障。
    /// </summary>
    /// <param name="duration">屏障持续时间（秒）</param>
    public void Initialize(float duration)
    {
        _remainingTime = duration;
        _isFadingOut = false;
    }
    
    private void Update()
    {
        if (_isFadingOut) return;
        
        _remainingTime -= Time.deltaTime;
        
        if (_remainingTime <= FadeOutDuration)
        {
            // 开始淡出
            StartCoroutine(FadeOut());
            return;
        }
        
        // 呼吸效果
        float t = (Mathf.Sin(Time.time * Mathf.PI * 2f / BreathPeriod) + 1f) / 2f;
        float alpha = Mathf.Lerp(BreathMin, BreathMax, t);
        
        Color c = _renderer.color;
        c.a = alpha;
        _renderer.color = c;
    }
    
    private IEnumerator FadeOut()
    {
        _isFadingOut = true;
        Color startColor = _renderer.color;
        float elapsed = 0f;
        
        while (elapsed < FadeOutDuration)
        {
            elapsed += Time.deltaTime;
            Color c = startColor;
            c.a = Mathf.Lerp(startColor.a, 0f, elapsed / FadeOutDuration);
            _renderer.color = c;
            yield return null;
        }
        
        // 销毁或回收到对象池
    }
}
```

## 6. 礼屏障刺刷新（bullet_li_barrier_thorn）

### 6.1 实现方式

**不用 Particle System**——用多个 `SpriteRenderer`（短线段）在屏障内随机刷新位置。

### 6.2 视觉规格

| 参数 | 值 | 说明 |
|------|-----|------|
| 刺数量 | 8 根短线 | 屏障内同时显示8根刺 |
| 刺尺寸 | 长 8px × 宽 2px | 小短线段 |
| 刷新频率 | 每 0.2s（5/s） | 每0.2秒随机重新分布位置 |
| 刺颜色 | #FFFFFF（白色） | 与屏障同色 |
| 刺位置范围 | 屏障半径内随机 | 在屏障圆内随机分布 |

### 6.3 实现方案

```csharp
/// <summary>
/// 礼屏障刺控制器。在屏障半径内随机刷新8根短线的位置。
/// 每0.2s刷新一次，模拟"礼刺5/s"的视觉提示。
/// </summary>
public class BarrierThornController : MonoBehaviour
{
    [SerializeField] private int _thornCount = 8;
    [SerializeField] private float _refreshInterval = 0.2f;
    [SerializeField] private float _barrierRadius = 0.64f; // 半径1单位 = 64px = 0.64单位
    
    private SpriteRenderer[] _thorns;
    private float _timer;
    
    private void Awake()
    {
        _thorns = new SpriteRenderer[_thornCount];
        
        // 创建8个子物体作为刺
        for (int i = 0; i < _thornCount; i++)
        {
            var thornObj = new GameObject($"Thorn_{i}");
            thornObj.transform.SetParent(transform, false);
            var sr = thornObj.AddComponent<SpriteRenderer>();
            sr.sprite = SpriteGenerator.Generate(SpriteShape.Rectangle, 8);
            sr.color = Color.white;
            sr.sortingOrder = 2; // 在屏障之上
            _thorns[i] = sr;
        }
    }
    
    private void Update()
    {
        _timer += Time.deltaTime;
        
        if (_timer >= _refreshInterval)
        {
            _timer = 0f;
            RefreshThornPositions();
        }
    }
    
    private void RefreshThornPositions()
    {
        foreach (var thorn in _thorns)
        {
            // 在屏障半径内随机位置
            Vector2 randomPoint = Random.insideUnitCircle * _barrierRadius;
            thorn.transform.localPosition = randomPoint;
            
            // 随机旋转
            thorn.transform.localRotation = Quaternion.Euler(0, 0, Random.Range(0f, 360f));
        }
    }
}
```
